# Practica 3 - Herencia, Validacion y Menjo de excepciones en php

## Objetivo
Desarrollar un sistema orientado a objetos robustos integrando herencia, validadciones de datos y manejo de exepciones para simular un entorno profesional.

## Descripcion del sistema
El sistema gestionna suarios de distintos roles dentro de una institucion. Esta compuesto por una clase base y dos clses derivadas, todas con validaciones que lanzan excepciones ante datos incorrectos.
