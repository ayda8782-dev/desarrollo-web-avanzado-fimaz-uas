# Practica 2 - Herencia en php

## Objetivo
Implementar herencia mediante la extension de las clases, reutilizando atributos y metodos de una clse base Usuario en una clase hija Admin.

# Explicacion de la herencia aplicada 
La herencia permite que una clase hija adquiera automaticamente todos los atributos y metodos public y proted de una clse base, evitando duplicar codigo.
